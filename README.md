# Fraud Detection with E-commerce and Credit Card Data

This project is developed as part of the 10 Academy AI Mastery Week 8–9 Challenge.
We build fraud detection systems using machine learning with advanced interpretability.

## Structure

- `notebooks/`: Exploratory analysis
- `src/`: Core logic (data processing, model training)
- `data/`: Raw and processed data (ignored by git)
- `api/`: FastAPI app for real-time predictions
- `tests/`: Unit tests for data processing
